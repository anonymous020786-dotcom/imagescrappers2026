Features

Everything you need to collect images — at any scale

From a single photo to a 50,000-page site crawl, Image Scraper Pro is built to be thorough, fast and private.

Finds images others miss

Highest-resolution srcset, lazy-load attributes, CSS backgrounds, ::before/::after, inline SVG, canvas, video posters, Shadow DOM and every iframe.

Smart filters

Filter by dimensions, file type, shape, file size, domain and main colour, search alt text with regex, and hide tracking pixels and ad images automatically.

Bulk download & ZIP

Download hundreds of images with progress, pause and resume, or pack them into one ZIP — split automatically for huge sets — with your own file-name templates.

Crawl whole websites

Paste thousands of URLs or crawl a site via links, pagination and sitemap.xml. Depth, scope and speed controls, and robots.txt respected by default.

Edit, convert & clean

Convert to WebP, PNG or JPEG, resize, crop, watermark and hit a target file size. Strip EXIF and GPS data before you share a photo.

Private by design

Everything runs inside your browser. No account, no analytics, no remote servers. Open source, so you can check every line.

Select exactly what you need

Shift-click ranges, select all, invert, then filter by size presets like ≥800 px or HD. Analyze fetches the exact byte size, real type and true dimensions of every image.

  • Perceptual-hash duplicate detection
  • Keep the best copy of each duplicate group
  • Sort by resolution, size, name, type or domain

Preview every detail

Zoom up to 12×, pan, browse with the arrow keys and see the full metadata: dimensions, type, size, alt text, source, colour palette, camera data and licence information.

  • Reverse image search with Google Lens, Bing, TinEye or Yandex
  • Jump to the image on the original page
  • Copy the image or its URL in one click

Scrape an entire website

The crawler follows links, "next page" buttons and sitemaps, with fast HTML mode for hundreds of pages per minute or full-render mode for JavaScript-built galleries.

  • Pause, resume and stop with a live activity log
  • URL pattern generator: photo[001-500].jpg
  • Send results straight to the dashboard

One click from the toolbar

The popup shows an instant image count and the largest images on the page. Quick download uses your saved filters and naming rules — or press Alt+Shift+D.

  • Right-click menus for single images and linked pages
  • Side panel that follows the tab you are on
  • Light and dark themes, settings synced across devices
Image SEO audit NEW

Rank higher in image search, and look great when shared

Click Audit on any page — or on a whole crawled site — to see what is holding its images back, with a clear fix for every finding.

  • Alt text quality — missing, generic ("image", "IMG_1234.jpg"), keyword-stuffed, too long or reused
  • Descriptive file names — flags camera defaults and hashes, even behind image CDNs
  • Social sharing images — og:image and Twitter cards present, 1200×630, 1.91:1, https
  • Structured data — an image in JSON-LD or microdata for rich results
  • Speed — oversized files, WebP savings (measured), lazy-loading and layout shift
  • Google image sitemap — export a ready-to-submit .xml for Search Console

How it works

From page to folder in three steps

  1. Open any page

    Click the toolbar icon or press Alt+Shift+I. The extension scans every frame and counts the images instantly.

  2. Filter & review

    Open the dashboard, narrow the results with filters, preview in the lightbox and run the SEO audit if you like.

  3. Download

    Save the selection as files or a ZIP, converted and named the way you want — or export a list, PDF, contact sheet or image sitemap.

FAQ

Frequently asked questions

Is Image Scraper Pro free?

Yes. It is free and open source under the GPL-3.0 licence, with no account, no ads and no paid tier.

Does the extension collect my data?

No. Everything — scanning, editing, metadata removal, the SEO audit, PDFs and collections — runs in your browser. There is no analytics or tracking, and nothing is sent to the developer. Only reverse image search, when you choose it, opens the search engine you pick. Read the privacy policy.

Which browsers are supported?

Chrome, Microsoft Edge, Brave, Opera, Vivaldi, Firefox (desktop and Android, version 121+) and Safari 16.4+ on macOS, all built from the same Manifest V3 code.

How do I install it from the ZIP file?

Unzip the download, open chrome://extensions (or edge://extensions), turn on Developer mode, click Load unpacked and choose the unzipped folder. In Firefox, open about:debugging, choose This Firefox and click Load Temporary Add-on. The install guide covers every browser.

What does the image SEO audit check?

Missing, generic, keyword-stuffed, overly long or reused alt text; non-descriptive file names; missing or undersized Open Graph and Twitter images; missing structured-data images; oversized files; images that could be WebP; and lazy-loading mistakes. It exports a CSV report and a Google image sitemap.

Can it download images from a whole website?

Yes. The bulk scraper accepts thousands of URLs, and the crawler follows links, pagination and sitemap.xml with depth, scope and speed controls. It respects robots.txt by default.

Am I allowed to use the images I download?

That depends on each image's licence and the website's terms. The extension shows the creator, credit and licence a page or file states, and records each image's source in ZIP downloads, but it is not legal advice. Please respect copyright.
